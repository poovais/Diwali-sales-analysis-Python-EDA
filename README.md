Diwali Sales Analysis using Python

Project Overview

This project performs Exploratory Data Analysis (EDA) on a Diwali Sales dataset to understand customer purchasing behavior during the festive season. Using Python and data visualization libraries, the analysis identifies key sales trends, customer demographics, and product preferences, providing valuable business insights for data-driven decision-making.

Problem Statement

Businesses experience significant sales during festive seasons like Diwali. Understanding customer behavior helps organizations optimize marketing strategies, inventory planning, and customer engagement.

This project aims to analyze Diwali sales data and generate meaningful insights that can support business growth.

Key Insights

Female customers contribute more to total sales.
Customers aged 26–35 years are the highest spenders.
Married customers make significant purchases.
Uttar Pradesh, Maharashtra, and Karnataka generate the highest sales.
IT, Healthcare, and Aviation professionals are among the highest spending customer groups.
Food, Clothing, and Electronics are the most popular product categories.
Business Recommendations

Target female customers with personalized festive offers.
Increase marketing efforts for customers aged 26–35.
Focus promotions in high-performing states.
Increase inventory for top-selling product categories.
Implement customer segmentation for targeted campaigns.
